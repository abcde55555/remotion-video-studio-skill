# 文案表达 SOP

## 1. 表达公式

**钩子（和你有关）→ 承诺（我能给你什么）→ 结构（三层/三步）→ 证据（场景+数字）→ 边界（诚实）→ 收尾（行动/情绪）**

## 2. 开场时间口径

| 距发布 | 口播 | 屏上 |
|---|---|---|
| 当天 | 「今天，X 发布了…」 | `X · YYYY.MM.DD` / `X 正式发布` |
| 次日 | 「昨天，X 发布了…」 | 同上 |
| 本周 | 「前几天，X 发布了…」 | 同上 |
| 1–4 周 | 「最近，X 发布了…」 | 同上 |
| 已上线 | 「X 现在可以用了」 | `X · AVAILABLE NOW` |
| 回顾 | 「一年前的今天…」 | `2024 → 2026` |

**屏上不写「就在刚刚」**（会过期）；时间词只出现在口播第一句；日期不确定用「近期/最近」。

## 3. 段落四拍

1. 结论句（人话）
2. 场景/动作（你能做什么）
3. 证据（数字/对比/测试）
4. 人话总结（可上字幕）

## 4. 句法规则

| 规则 | 做法 |
|---|---|
| 短句 | 一句 ≤25 字；字幕 ≤22 字 |
| 第二人称 | 每段至少一个「你」 |
| 功能翻译 | 「支持 X」→「你能 X」 |
| 数字落地 | 数字后加「什么概念/对比」 |
| 对比 | 至少一处「过去 vs 现在 / 有它 vs 没它」 |
| 类比 | 抽象概念配日常类比（subagent→小助手；护栏→门禁） |
| 口语连接 | 其实/就是/所以/那，每段 1–2 个 |
| 边界 | 主动说一句局限 |
| 朗读测试 | 卡壳就改 |

## 5. 句式库（节选）

- 「你有没有发现，同样是 ___，有人 ___，有人 ___？」
- 「这可能是你今年最该学会的 ___。」
- 「接下来我用 ___ 个例子，把这件事讲透。」
- 「过去 ___，现在 ___。」
- 「这不是 ___，而是 ___。」
- 「你只要 ___，它就会 ___。」
- 「注意看这里：___。」
- 「这个数字什么概念？相当于 ___。」
- 「它现在还不擅长 ___，所以别指望它 ___。」
- 「你可以去 ___ 试试，回来告诉我 ___。」

## 6. 改写流程（30 分钟/稿）

通稿版 → 翻成人话 → 钩子提前 → 拆长句 → 配字幕 → 朗读计时 → 自检（10 条）。

## 7. 发布前自检

- [ ] 第一句和观众有关
- [ ] 前 5 秒有对比/结果
- [ ] 功能翻成「你能___」
- [ ] 每 30 秒有具体场景/数字
- [ ] 无 >25 字长句
- [ ] 「你」每段至少一次
- [ ] 讲了边界
- [ ] 每段有人话总结
- [ ] 结尾有行动/提问
- [ ] 读起来像朋友聊天不像通稿
