# 动画特效风格库（24 种）

来源参考：一条用 Claude + Remotion 纯代码做 24 种风格的教学片（每段 3–6 秒、固定版式）。可作为「风格选择菜单」：先选风格，再写提示词。

## 统一版式（24 段共用）

```
左上分类标签 / 主标题（编号+名称）/ 全屏主视觉 / 右上水印
底部：技术关键词行（可直接喂 AI）+ 一句人话说明（效果承诺）
```

## 提示词结构

```
【风格】像 <参考>，<3 个关键词>
【画面】主体 <X>，背景 <Y>，配色 <Z>
【运动】<元素> 按 <节拍/缓动> 做 <动作>，<转场>
【版式】左上分类标签，主标题，底部关键词 + 一句人话说明
【技术】Remotion + SVG/Canvas/WebGL，纯代码，不用素材图
```
