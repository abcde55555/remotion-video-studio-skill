# 素材采集与版权

## 官方素材

| 类型 | 位置 | 抓法 |
|---|---|---|
| 发布文章 | `site.com/<slug>` | curl 直连；被拦用 reader 服务或浏览器 |
| 官方视频 | 页面 `<video>` / CDN `.mp4/.webm` | 正则抓 URL → curl → ffprobe 核对 |
| Poster/hero | CDN 图片 | 直接下载 |
| 文档/模型卡 | docs 站（部分支持 `.md`） | curl |
| 价格 | 官方 pricing 页 | curl |
| 图表 | 官方博客图片 | 抓图 + 读图取数 |

## 清单模板

| # | 素材 | 类型 | 来源 URL | 时间码/页码 | 用在哪 | 版权/标注 |
|---|---|---|---|---|---|---|

## 版权

- 官方视频/图片版权归原公司；仅学习/概念引用，片内标注来源，片尾非官方声明。
- 对外发布需授权或替换素材。
- 音乐/字体：只用可商用或自建（本方法用程序化原创音乐 + OFL 字体）。
- 第三方平台（小红书等）内容只作选题参考，不直接搬运。
