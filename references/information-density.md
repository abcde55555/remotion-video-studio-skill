# 信息密度：诊断与方案

## 症状

- 每屏 1–2 个信息点；每分钟数字少；大量 2s+ 空镜；旁白重复屏上大字；无 TL;DR/小结/总结表；视频独特价值（demo/对比）未用足。

## 目标

| 指标 | 目标 |
|---|---|
| 每屏信息点 | 6–10 |
| 每分钟有效数字 | 30–45 |
| 静音可读率 | ≥80% |
| 2s 以上空镜 | 0–1 处 |
| TL;DR/章节小结/总结表 | 齐全 |

## 三层信息密度

1. **速读层（屏上）**：数字、表格、标签、来源脚注。
2. **解释层（旁白）**：因果/类比/边界，不重复屏上文字。
3. **证据层（画面）**：官方 demo、before/after、图表。

## 每屏预算

- 主数字 1 + 支撑数据 3–5 + 结论 1 句 + 来源 1 行。
- 主数字旁必须有对比或量级解释。
- 禁止「一个大数字 + 一句口号」。
- 每 10s 至少 2 个新事实/数字；句间 ≤0.8s。

## 自检

- [ ] 开头 5s TL;DR
- [ ] 每屏 ≥6 个信息点
- [ ] 每章一行数据小结
- [ ] 片尾总结表/总结行
- [ ] 旁白不复述大字
- [ ] 静音能懂 ≥80%
