# QA 检查表

## 事实
- [ ] 每个数字/日期有官方来源（URL + 抓取日）
- [ ] 无官方未公布参数、无编造
- [ ] 竞品数字标注「官方自测/第三方」，无「全面领先」
- [ ] 「最高/第一」类表述限定口径（如 Anthropic 测过的已发布模型）

## 规格/音频
- [ ] 帧数/时长正确（如 2700 帧 / 90.000s）
- [ ] 集成响度 −14～−16 LUFS；真峰值 ≤ −1 dBFS
- [ ] 无黑帧/空白帧
- [ ] 音乐与旁白比例合理（人声清晰）

## 配音/字幕
- [ ] 每句非静音、起点偏差 ≤±5 帧
- [ ] 无重叠、不跨画面切换
- [ ] 字幕与 SRT 逐字逐帧一致
- [ ] 单行、无裁切/压字、深/浅场自适应

## 画面
- [ ] 8–10 个时间点抽帧：无重叠/出血/裁切
- [ ] 数据卡/图表/视频窗口不压字幕条
- [ ] 官方素材有「官方演示/官方示例」标注
- [ ] 片尾非官方声明可见

## 可复现
- [ ] PNG 序列 + 单线程 x264 连续两次 md5 一致
- [ ] 记录 md5/大小/响度到交付文档

## 交付
- [ ] 成片 + SRT + 6 份文档 + 预览 + 包
- [ ] 发送清单：文件/大小/用途/建议 IM
