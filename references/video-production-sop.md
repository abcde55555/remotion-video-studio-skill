# 视频生产 SOP

## 1. 体裁决策（开工前必做）

| 体裁 | 时长 | 结构 | 音频 | 适合 |
|---|---|---|---|---|
| 概念片 | 30–90s | 钩子→核心命题→3–5 记忆点→收尾 | 音乐为主，8–12 句旁白或纯字幕 | 发布会预告、品牌片、社媒投放 |
| 解说片 | 3–4min | 封面钩子→总论点→5–8 章节→选型/价格→来源 | 连续旁白 900–1200 字，BGM 轻铺底 | 模型评测、发布解读、教程 |
| 双版本 | 两者 | 解说版先写，再压概念版 | 同一素材两套音频 | 重要发布 |

**不要默认 90 秒**：先问「让观众记住，还是学会？」。

## 2. 素材采集

- 官方源：发布页 `<video>`/CDN、poster、hero、博客内嵌视频、官方图表、模型卡/文档、价格页。
- 抓取：curl 直连；被拦时用浏览器/reader 服务；记录 URL + 抓取日 + 时间码。
- 覆盖率门槛（解说片）：官方视频 ≥3 段、截图/poster ≥5 张、重绘图表 ≥3 张、图标/示意 ≥3 个、封面 1 张；概念片减半。
- 视频素材：截 2–4s，标注「官方视频截取 + 时间码 + 来源」；版权仅学习/概念引用。

## 3. 分镜模板

| 模板 | 结构 | 用途 |
|---|---|---|
| 章节封面 | 大号章节号 + 章节名 + 一句问题 | 每章 2–3s |
| 信息页 | eyebrow + 大标题 + 3–5 行要点 + 图/示意 + 底部 takeaway | 讲结论 |
| 证据页 | 标题 + 图表/官方截图/视频 + 数据标注 + 来源脚注 | 讲证据 |

节奏：解说 6–12s/页（6–8 刀/分钟）；概念 2–4s/卡（15–25 刀/分钟）；页内动画持续（图表生长/count-up）。

## 4. 信息密度（信息型视频）

- 每屏 6–10 个信息点（数字/表格/标签/对比）。
- 开头 5s TL;DR（3–5 个关键数字）；每章一条数据小结；片尾总结表。
- 旁白不复述屏上大字，只解释「为什么/意味着什么」。
- 目标：每分钟有效数字 ≥30；静音可读率 ≥80%；2s 以上空镜 0–1 处。

## 5. 平台包装

- 封面 3:4（小红书）或 16:9；标题 ≤20 字：对象 + 变化/数字 + 结果。
- 正文 600–900 字：钩子复述 + 分章小标题 + 数字 + 结论 + 来源 + 话题标签 4–6 个。
- 声明：AI 生成内容声明（如适用）+ 非官方声明 + 素材版权说明。

## 6. 时间预算（单人 + agent 团队）

| 阶段 | 解说片 3–4min | 概念片 90s |
|---|---|---|
| 资料/事实 | 1–2h | 1–2h |
| 文案 | 1–2h | 0.5h |
| 素材 | 1–2h | 0.5–1h |
| 分镜/镜头表 | 1h | 0.5h |
| 配音 | 0.5h TTS | 0.3h |
| 动画 | 4–8h | 2–4h |
| 渲染/QA/包装 | 1–2h | 1h |
